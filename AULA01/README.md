# JavaScript - Resumo

## História

- Criado por **Brendan Eich em 1995**
- Passou pelos nomes **Mocha** e **LiveScript** antes de se chamar JavaScript.
- O nome foi escolhido por estrategia de marketing, aproveitando a popularidade do Java.
- Começou como ua linguagem simples de scripts e evoluiu para uma das principais tecnologias da web.

## Importancia no Dev Web

- Interatividade em Tempo Real: Sem o JS, a web seria composta apenas de documentos estáticos em HTML e CSS. Ele permite alterar o conteúdo da tela sem precisar recarregar a página inteira.

- Linguagem Universal: É suportado por padrão em 100% dos navegadores modernos **(Chrome, Firefox, Safari, Edge)** sem necessidade de plugins adicionais.

- Desenvolvimento Full-Stack: Com a criação do **Node.js**, os desenvolvedores usam uma única linguagem para construir tanto a interface visual (front-end) quanto os servidores e APIs (back-end).
